# git-context-mcp

MCP server for git operations, GitHub PRs, and GitLab MRs. Covers local git (status, log, diff, blame, branches, stash), GitHub PR lifecycle (list, view, diff, create, comment, merge, checks), and GitLab MR lifecycle (list, view, create).

**Deps:** `gh` CLI for GitHub, `glab` CLI for GitLab.

Full docs: [github.com/Sakethv7/agent-mcps](https://github.com/Sakethv7/agent-mcps)
