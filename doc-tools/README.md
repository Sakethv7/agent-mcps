# doc-tools-mcp

MCP server for PDF text extraction and OCR. Exposes `pdf_info`, `detect_text_layer`, `extract_text`, `ocr_pages`, `rasterize_pages`, and `extract_toc` as callable tools.

**System deps:** `brew install poppler tesseract` / `apt-get install poppler-utils tesseract-ocr`

Full docs: [github.com/Sakethv7/agent-mcps](https://github.com/Sakethv7/agent-mcps)
