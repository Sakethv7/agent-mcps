# data-tools-mcp

MCP server for data file profiling and database schema inspection. File tools: `profile_file`, `list_sheets`, `sample_file`, `find_column_in_file`, `compare_schemas`. Database tools (SQLAlchemy): `list_tables`, `describe_table`, `sample_rows`, `find_column`, `run_query`.

Supports CSV, Excel, Parquet, JSON, TSV, and any SQLAlchemy-compatible database.

Full docs: [github.com/Sakethv7/agent-mcps](https://github.com/Sakethv7/agent-mcps)
