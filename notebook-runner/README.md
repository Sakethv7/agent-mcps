# notebook-runner-mcp

MCP server for reading, editing, and executing Jupyter notebooks. Exposes `get_notebook_info`, `list_cells`, `get_cell`, `run_cell`, `run_all`, `run_range`, `insert_cell`, `update_cell`, `delete_cell`, `clear_outputs`, `get_errors`, `get_variables`, and `export_to_script`.

Full docs: [github.com/Sakethv7/agent-mcps](https://github.com/Sakethv7/agent-mcps)
